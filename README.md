# Coolmic Webcomic Downloader

A custom browser script constructed to seamlessly capture and export high-resolution panel sequences from Coolmic directly to your local storage.

## ✨ Core Capabilities

* **Deep Network Scanning:** Hooks into background data operations to actively identify and extract picture arrays the moment they load on the page.
* **Dynamic Data Parsing:** Intelligently navigates nested backend structures to locate valid media links, ensuring compatibility with varying site updates.
* **Robust Access Fallbacks:** Uses anonymous requests with custom headers to fetch the highest quality raw files, automatically reverting to standard links if server access is denied.
* **Floating Control Widget:** Integrates a semi-transparent, repositionable status menu that tracks extraction progress without blocking your reading view.
* **Automated Directory Export:** Saves numerically sequenced files (e.g., `page_001.jpg`) straight into a newly generated folder matching the episode name, completely bypassing zipped archives.

## 🚀 Setup Instructions

1. **Requirements:** Install a userscript manager (such as Tampermonkey) to enable advanced local storage and file-saving privileges.
2. **Installation:** Add the tool to your dashboard via the provided Greasyfork repository.
3. **Execution:** Navigate to a target episode on the website.
4. **Save:** Once the movable widget indicates the media is ready and displays the total count, click it to begin the automated folder extraction.
